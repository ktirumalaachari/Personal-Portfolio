## 🚀 Key Highlights & Architectural Features

- **Cinematic 7-Stripe Curtain Preloader**: GSAP-driven bottom-up wave reveal with a real-time `0%` to `100%` counter and synchronized hero landing entrance physics.
- **Interactive Student Identity Lanyard**: Physical drag, hover-tilt spring physics, barcode serial verification, and high-fidelity student ID card.
- **ScrollStack 3D Curved Showcase**: Custom-engineered 3D cards stack for 8 flagship projects with depth transforms, dynamic shadows, and live demo routes.
- **Ephemeral AI Assistant (`@tirumala-assistant`)**: Floating glassmorphic AI chat widget powered by localized semantic retrieval to answer recruiter queries about skills, projects, and certifications.
- **Interactive Résumé / CV Request Modal**: Controlled recruiter request modal with tactile input underline springs, haptic feedback, and automated notification delivery via EmailJS.
- **Instant WebRTC Video Calling & Calendar Scheduling**: Zero-friction 1-on-1 strategy call bookings and instant Jitsi Meet room creation directly from the Contact section.
- **Ultra-Smooth Inertial Scroll & Mobile Haptics**: Integrated `@studio-freight/lenis` smooth scrolling and `navigator.vibrate` tactile feedback on clicks, buttons, and navigation events.

## 💻 Getting Started Locally

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **bun**

### 1. Clone the repository
```bash
git clone https://github.com/ktirumalaachari/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 4. Build for production
```bash
npm run build
```
The compiled output will be generated in the `dist/` directory.

### 5. Preview production build
```bash
npm run preview
```
